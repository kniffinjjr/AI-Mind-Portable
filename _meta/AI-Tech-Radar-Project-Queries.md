# Project → skill search queries (template)

Used on every **run radar** as a Discover source. **Instance rows belong in My Mind / Work Mind**, not in this portable Vault.

Copy the table below into `MY_MIND_ROOT/_meta/radar-queries.md` (or Work-Mind) and fill your slugs.

## Template

| Mind | Project slug | Search seeds (skills / tools / patterns) | Existing skills to prefer |
|------|--------------|------------------------------------------|---------------------------|
| My-Mind | `<slug>` | 2–4 keywords | `<skill>` |
| Work-Mind | `<slug>` | 2–4 keywords | `<skill>` |

## Query construction rules

1. Prefer **2–4 seeds per active project**.
2. Search X + GitHub for: `skill`, `MCP`, `agent`, `automation`.
3. Score with Domain Fit high for that project.
4. Strengthen an existing skill when possible; else Watchlist.
5. Work-Mind hits stay work-safe.
6. Skip `_template` and archived projects.

## On each radar run

1. Read **your** local query map (not this template).
2. Search seeds that lack a recent Watchlist hit.
3. Report under **Project skill search**.
