# AI Mind — Portable Architecture

**Public portable edition: overall agent architecture plus a representative set of agent profiles.**

This is the portable subset of a larger private Agentic OS. It carries the controlling architecture (Harness · Loop · Graph), methodology, process, and a few generic agent profiles to prove functionality and stay flexible. Domain skills, tool catalogs, research captures, and personal/work residue live in the private vault and in your own My Mind / Work Mind — not here.
