# OCJ Cleaners — demo website

Static multi-page proposal site for **OCJ Cleaners**, Mount Pleasant, TX.

## Pages

- `index.html` — Home  
- `services.html` — Services  
- `about.html` — About  
- `contact.html` — Contact (call + map; form is demo-only)

Primary CTA: **Call (903) 717-2456**

## Run locally

```bash
cd demos/ocj-cleaners
python3 -m http.server 8765 --bind 127.0.0.1
# open http://127.0.0.1:8765/
```

## Brand notes

Colors and hero photography adapted from the public Facebook cover / storefront capture and Chamber / directory listings. Facebook posts/About were login-walled — see `docs/ocj-cleaners-brand-handoff.md` in the Project store.
