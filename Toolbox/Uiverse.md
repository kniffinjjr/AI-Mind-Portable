# Uiverse

**One-liner:** Community UI element inspiration (buttons, cards, loaders); copy HTML/CSS — not a product design system.

**Links:**

- https://uiverse.io/
- Galaxy-related community assets as linked from radar bookmarks

## When to use

- Visual inspiration / one-off CSS patterns
- Prototyping motion or control chrome

## When not to use

- As the system of record for tokens or accessibility
- Bulk-paste without contrast/hierarchy QA

## Agent pairing

`design-system` first → paste sparingly → `pixelslop` / `a11y-build`.
