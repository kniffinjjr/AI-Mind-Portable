# KiCad MCP

**One-liner:** Schematic + PCB automation for KiCad 10 via mixelpixx KiCAD-MCP-Server (~137 tools).

**Links:**

- Typical server: mixelpixx/KiCAD-MCP-Server (or equivalent)
- KiCad 9/10 from https://www.kicad.org/

## When to use

Schematic/PCB automation, ERC/DRC, fab export.

## When not to use

Mechanical CAD (use FreeCAD/Fusion/Inventor).

## Agent pairing

`kicad`, `kicad-schematic`, `kicad-pcb-layout`, `kicad-erc-drc`, `kicad-jlcpcb-export`, `hardware-forge`.
