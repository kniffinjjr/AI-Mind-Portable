# Design Reference Galleries

**One-liner:** Curated visual reference sites for web, mobile, social, heroes, navbars, CTAs, and motion — human inspo, not a design system.

**Source list:** https://x.com/tranmautritam/status/2088189728432799797

## Catalog

| Site | Focus |
|------|--------|
| https://www.inspora.design/ | Recent visual design (web, branding, motion, 3D, print); quiet curation |
| https://recent.design | Daily best-of design, websites, tools |
| https://posts.design | Social post / launch card / announcement layouts |
| https://loadmo.re | Bold mobile website gallery |
| Hero / navbar / CTA pattern libraries (from same thread) | Landing structure references |
| UI animation & interaction detail galleries (from same thread) | Motion reference |

For **AI-readable systems** (tokens as markdown), use [[Toolbox/Refero-Styles]] instead of screenshots alone.

## When to use

- Mood boards and direction before building
- Checking hero / nav / CTA patterns against `landing-page` skill
- Motion reference alongside `web-motion`

## When not to use

- As the system of record for tokens or accessibility
- Copying layouts wholesale without hierarchy/contrast QA
- Replacing [[Toolbox/Refero-Styles]] or `design-system` skill

## Agent pairing

| Task | Skills |
|------|--------|
| Structure | `landing-page`, `product-page`, `site-ia` |
| Tokens | `design-system` (+ Prefer Refero for structured systems) |
| Components | `Magic-UI`, `Uiverse` sparingly |
| QA | `pixelslop`, `better-interface`, `a11y-build` |
