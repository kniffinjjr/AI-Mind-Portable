# Hypervault

**One-liner:** 3D “cyberpunk city” view of an Obsidian vault; projects as buildings (status→color, priority→height); launch agents into `projectDir`.

**Links:**

- https://studio.pardesco.com/hypervault
- Open plugin ecosystem (AGPL community builds)

## Work use (required)

Use the **Codex Mind Pack** work wiring — do not point the city at personal My-Mind on a work machine:

- Pack doc: `codex-mind-pack` → `core/Hypervault-Work-Mind.md`
- Template: `templates/Project-Overview-Hypervault.md`
- Optional PATHS key: `HYPERVAULT_VAULT` (work-only root)

## When to use

- Many concurrent projects; need spatial status dashboard
- Agent launch into known project directories

## When not to use

- As a replacement for Run Knowledge Extract, GrokRarian, or three-mind IP split
- Single vault mixing personal + company notes

## Agent pairing

`obsidian-markdown` · Librarian/PATHS · `Run-Knowledge-Extract` after meaningful runs
