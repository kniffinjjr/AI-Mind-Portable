# Dual architecture residue: HTML for humans, JSON for agents

Prompt pattern: deeply analyze a repo and emit two durable artifacts:

1. Self-contained interactive HTML (nodes, edges, flow highlighting, tooltips)
2. JSON `{nodes, edges, flows}` consumable by another agent

**Mapping:** Classic Intentional Residue. The dual-output pattern (human visual + agent-readable structure) is the useful technique. Applied to our own mind architecture in `Concepts/Architecture-Visual.html`.
