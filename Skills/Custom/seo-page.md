# SEO Page

Structure pages so **humans and crawlers** understand topic, intent, and usefulness. Not black-hat tricks.

## Triggers

SEO page · meta tags · search intent · organic landing · title description · heading structure SEO · internal linking · snippet

## Principles

1. **Intent match** — informational, commercial, transactional, navigational; page type follows intent.
2. **One primary topic per URL** — don’t dilute with unrelated sections.
3. **Titles and H1 aligned** — clear, specific, not keyword stuffing.
4. **Structure is SEO** — headings, lists, tables, FAQ where they help readers.
5. Technical SEO (CWV, indexation) needs engineering verification—label gaps.

## Checklist

| Element | Notes |
|---------|--------|
| Title | Unique; ~50–60 chars practical; primary phrase near front |
| Meta description | Compelling summary; not required for ranking but helps CTR |
| H1 | One; matches promise of title |
| H2–H3 | Outline scannable subtopics |
| Internal links | To/from related hubs with descriptive anchors |
| Image alt | Describe function/content |
| Canonical | When duplicates exist |
| FAQ | Real questions; eligible for rich results when appropriate |

## Workflow

1. Define query intent and primary phrase (honest match).
2. Outline sections that answer the intent fully.
3. Draft title, H1, meta description.
4. Map internal links to IA (`site-ia`).
5. Flag thin content, duplicate intent with other URLs, or missing proof.
6. For conversion SEO pages, coordinate CTA with `landing-page`.

## Out of scope (hand off)

- Link schemes, cloaking, doorway pages — refuse
- Pure keyword lists without page substance
- Server/index config — note for engineering

## Handoffs

- IA / URL map → `site-ia`
- Conversion layout → `landing-page`
- Long-form quality → Page Master
- Performance design notes → engineering / `responsive-shell`
