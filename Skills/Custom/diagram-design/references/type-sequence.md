# Type — Sequence

**Use when:** time-ordered messages between actors (agents, human, tools).

## Layout

- Vertical lifelines; time flows down.
- Sync messages solid; async dashed.
- Activation bars optional and thin.

## Rules

1. Actors across the top — max ~6 or split.
2. Message labels short (verb + object).
3. Notes for residue/handoff envelopes, not as fake messages.
