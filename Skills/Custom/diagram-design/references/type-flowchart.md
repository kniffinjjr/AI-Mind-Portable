# Type — Flowchart

**Use when:** decision logic or a pure process spine (e.g. W0–W7).

## Layout

- Top-to-bottom or left-to-right spine.
- Diamond = decision; rect = action; rounded = start/end.
- Side branches for rare paths (W2 design, W6 improve) — not equal weight to the main path.

## Rules

1. Orthogonal elbows.
2. One primary happy path visually dominant (stroke or accent on 1–2 nodes).
3. Do not embed nested architecture inside flowchart nodes.
4. Labels on decisions are questions or predicates, not essays.

## AI Mind mapping

W0 Boot → W1 Classify → branch to W2 / W3 / W4 / W5 / W6 / W7. Grain tags on steps, not a second diagram.
