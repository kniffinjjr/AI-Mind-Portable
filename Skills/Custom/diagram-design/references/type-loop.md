# Type — Loop / flywheel

**Use when:** reinforcing cycle where the last step feeds the first; optional shared-memory hub.

## Layout

- Circular or rounded polygonal cycle of 3–6 stages.
- Hub in the center = shared memory / Probe Ledger / residue store.
- Solid arrows = forward cycle; dashed = write-backs to hub.

## Rules

1. Name each stage with a verb + evidence.
2. Hub is not a stage — it is state.
3. Call out the stopping rule or until probes PASS explicitly.
4. Density: if more than 6 stages, split outer vs inner loop.

## AI Mind mapping

OUTER RAI loop: run probes → classify failure → one lever → re-run → write Probe Ledger → until PASS or escalate.
